# 👕 Enhanced CVAE for Fashion-MNIST

Conditional Variational Autoencoder implemented in PyTorch for image generation on the Fashion-MNIST dataset.

## Features

- Conditional Variational Autoencoder (CVAE)
- Conditional Batch Normalization (CBN)
- KL Annealing
- Normalizing Flows
- FID Evaluation
- UMAP Latent Space Visualization

## Dataset

Fashion-MNIST

## Technologies

- PyTorch
- Torchvision
- NumPy
- Scikit-learn
- UMAP
- Matplotlib

## Results

Generation of new class-conditioned Fashion-MNIST samples with improved latent-space representations.

## Academic Context

Project developed as part of a Deep Learning course focusing on conditional generative models.
